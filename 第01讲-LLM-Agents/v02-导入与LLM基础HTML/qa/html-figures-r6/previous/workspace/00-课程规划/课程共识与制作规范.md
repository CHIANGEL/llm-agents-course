# 课程共识与制作规范

更新日期：2026-10-19。

## 已确定的课程要求

本课程面向 MBA，共三次课。第一讲聚焦 LLM Agents，时长 3 小时。已完成参考材料整合、课程规划和逐页内容规划；2026-10-18 教师先授权制作导入与LLM基础部分的HTML样稿，随后授权继续制作Prompting部分，最后授权完成第一讲全部后续内容。第二、三次的主题与安排尚未确定。

LLM 入门基础和 Prompting 是 Agents 的前置。LLM 原理讲到 next token prediction，Token 仅作基本解释，不展开 tokenization 算法、BPE 或分词演示。Prompting 使用原课程内容，并整合教师补充的《Prompting技巧.pdf》。

全程采用教师讲解、案例对照与演示，不安排练习、小组任务、互评、测验或课堂作业。总时长 180 分钟，含一次 10 分钟休息；这是教师已确定的安排。

### 2026-10-18 样稿反馈：后续必须遵从

1. 课件正文、图注、演示状态和材料展开区不出现防御性文字。来源性质、材料版本和执行记录写入资料档案，不作为教学画面的免责声明。删除这类提示时保持事实准确；概念边界应直接讲清其机制与影响。
2. 全讲、章节和子章节均采用总分总。开头明确本节范围、要点及逻辑关系；中间逐项展开；结束归纳要点并回到关系图。目录说明讲授位置，总览说明内容关系，两者各司其职。
3. 全讲目录分为“LLM 基础”“Prompting”“Agents：Externalization & Internalization”三个一级主题。Agents 下设工具调用、Memory、Skills、Harness、外化与内化整合，原规划中第 3–7 部分据此纳入同一上层结构。

以上为教师已确定要求，适用于当前样稿修改及后续全部制作。补充总览与小结时按教学逻辑增页，不以原样稿 13 页为固定上限。

## 措辞与解释

- 标题直接指出对象、问题或结论。用具体动作解释谁读了什么、做了什么、依据什么判断。
- 首次出现的术语补足中文含义；后续称呼保持稳定。不用更多陌生术语解释一个术语。
- 每页推进一步理解，复杂案例按材料、操作、结果分开呈现。图和文字共同解释。
- 不自行虚构全讲贯穿业务故事。各模块优先使用原课程真实文件和已有示例，MBA 关联通过任务要求、材料、操作范围与验收讲清。
- 来源、材料版本、执行记录与引用依据归档保存。画面直接说明概念和机制；结果描述与已有记录保持一致。生成内容、外部执行和结果反馈的区别，用参与者与动作图解释。
- 原教师心得保留作者属性。补充 PDF 中的作者经验不改写为教师亲历或通用实证结论。

## HTML 与配图

采用 16:9 白底；蓝标题与细线页眉、深蓝或黑正文、红色重点、右上交大建筑轮廓，沿用原课已确认样张。标题约 32–36 pt，主要正文约 20–24 pt，图内标签约 18–22 pt；最终以投影可读性检查，不靠缩字号塞材料。

HTML 保留可选择文字，默认整页显示，支持前后翻页、必要机制的手动前进与回退、图片放大和完整材料展开。来源资料另行归档。控件可隐藏，正文不放普通网站导航栏，底部固定两级课程进度条。进入大章节用分层全讲目录，章内切换明确当前位置；各章节及子章节按总览、展开与总结组织。总览用关系图解释后续内容怎样相连，总结回到同一结构并归纳要点。总分总不等于逐条揭示或机械重复目录页；同页对照能够讲清的内容一次展示。

每个核心机制都安排解释性配图。优先复用原课对象图、文件截图、产物截图和流程图；只有需要比较过程变化时才使用分步演示，并保留对照所需的背景。普通文字装框、放几个图标或整页 JSON 不算配图完成。真实论文图表保留原图与比较条件，不能用生成图替代证据。

正文展示能看清的关键材料；完整消息、提示词、文件包、程序与版本细节放展开区。新版不把原有长 JSON 页面原样作为 MBA 的主画面。
