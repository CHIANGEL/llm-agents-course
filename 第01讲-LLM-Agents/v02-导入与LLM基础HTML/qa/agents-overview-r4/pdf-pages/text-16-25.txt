从一篇 Review Paper 讲起
 • LLM Agent 的进步，已经不再只靠更大的模型、更多的参数了。未来真正决定 AI 能力上限的，
   是 “外部化”，把原本需要模型内部解决的认知负担，系统地转移到外部的基础设施中。

   • 换更强的基座模型，往往不如改进外部基础设施带来的提升显著。持久化记忆、可复用技能、
     标准化工具接口等等，这些「不属于模型」的东西，越来越决定着 Agent 能不能真正好用。

 • Agent Externalization 能够有效统合当下 LLM Agent 的各个看似独立的研究方向，例如
   Memory，Skill，Protocol，Harness Engineering 等。

人类的认知进化史
• 认知科学家 Don Norman 的「认知工件（Cognitive Artifacts）」理论。

  • 购物清单：不是让记忆力变强，而是把“回忆”变成“识别”

  • 地图：不是让方向感变强，而是把空间关系变成可见结构

  • 日历：不是让时间感变强，而是把未来承诺变成外部对象

• 外部工件的力量，在于它重新组织了问题的形式，让主体用现有能力更可靠地解决它。

• 权重（2022–2023）：

  • 能力几乎等同于模型参数，扩展定律主
    导叙事。奠定了基础，但知识难以选择

  • Prompt 工程、CoT 兴起，模型保持冻

    问题被部分转化为「识别」问题，但状
    态短暂，跨步骤协调始终脆弱。

• Harness 层（2024 至今）：

  • 可靠性依赖外部记忆、工具注册、协议、
    沙箱与编排。「Agent 工程越来越体现
    为 Harness 工程」，实现从会聊天到能
    做事的转变。

什么被外部化了？
• Memory：外部化状态

  • 原本负担：记住历史、上下文、偏好、经验

  • 任务变化：从 recall 到 retrieval

• Skills：外部化专业知识

  • 原本负担：每次重新组织流程

  • 任务变化：从 generation 到 composition

• Protocols：外部化交互结构

  • 原本负担：猜测格式、边界和下一步

  • 任务变化：从 ad-hoc conversation 到 structured exchange

• Harness：统一的认知环境外部化

  • 统合前三者，还包含了Permission、Control、Observability，探索能力边界
