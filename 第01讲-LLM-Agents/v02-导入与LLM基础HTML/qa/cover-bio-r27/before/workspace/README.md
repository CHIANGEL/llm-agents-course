# 零基础入门大模型智能体（文科版）

面向文科学院、没有编程或大模型基础的学习者。课程讲清 LLM、Prompting 和智能体的基本原理，更重视把可复用的方法与材料带回日常工作、科研和生活。本课程讲完大模型智能体即形成完整内容，不承接 MBA 的智能体前沿课或企业智能决策课。

## 立即打开

- 双击根目录的 **启动课件.command**，启动本机预览并打开浏览器。需要 Python 3；终端窗口保持开启，按 `Ctrl+C` 停止。
- 命令行运行：`python3 scripts/preview-course.py`，然后打开 [文科版独立预览](http://127.0.0.1:8876/?revision=humanities-setup-20261021#p=1&s=1)。
- 无 Python 时，可直接打开 [课件入口](第01讲-LLM-Agents/v02-导入与LLM基础HTML/index.html)。本地视频建议使用上述预览服务，支持拖动定位。

端口默认 `8876`，与 MBA 课件分开；若占用，可运行 `python3 scripts/preview-course.py --port 8877`。服务只监听本机。移动项目时保留整个目录。
