## 制作规范

- 沿用安泰课件风格 v1 和 [教师措辞与版式习惯](00-课程规划/参考资料/原课程规范/教师措辞与版式习惯.md)。写清对象与动作，不虚构教师经历，不套用抽象口号。术语首次出现补足中文解释，称呼保持一致。
- 全课程、章节和子章节采用总分总：先解释范围与关系，逐项展开，最后回到同一结构。每页推进一步理解，按需要拆页，不用分钟数倒推页数。
- 使用 HTML、可选择文字与解释性配图。白底、蓝标题与页眉、深蓝或黑正文、少量深红重点、交大建筑轮廓；完整提示词、消息、代码和文件另设阅读区。不得用整页图片代替 HTML 正文，不用普通文字框充当配图。
- 默认一次显示整页信息。必要的机制对照保留可选择、可暂停和可回退的控件；普通正文不逐条点击出现。长 Prompt 使用可滚动、可选择的黑色纯文本，原文不随摘要删减。
- 目录与底部两级进度可跳转，当前位置用深红强调。总目录顶部不加“已结束 → 接下来”横条；子章节内部保留承上启下的子目录。目录负责定位，总览解释内容关系。
- 复用已有优质图案、真实文件、产品演示和论文原图；正文及图内主要标签用 HTML 排版。配图、数字、过程、提示词和产物必须相互对应。
- 来源、材料版本和执行记录放本地档案，不转成教学画面的制作免责声明；影响结论的适用条件与概念区别仍应讲清。不把示意或未执行内容写成真实运行，不将趋势写成已部署事实。
- LLM 基础保留 Prompt、Context、Token、next token prediction 和 chat template 的连续解释；展示 Tokenization 转换结果，不展开算法或完整 BPE。Prompting 保留教师心得及补充 PDF 中已采用的十种方法；教学界面不提供 PDF 源文件链接。
- Agent 各组件称呼保持“工具调用 Tool Use、记忆 Memory、技能 Skills、协议 Protocols、Harness”。Memory 与 Skills 的过程列表只显示截至当前阶段的累积环节，保持固定顺序、字号和独立滚动。
- 视频手动播放，支持暂停、定位、调速、声音与放大；视频区按键不翻页，离页停止。使用支持 HTTP Range 的本地预览服务。
