# 零基础入门大模型智能体（文科版）——课程共识与制作规范

更新日期：2026-10-21。本文是当前文科版的课程定位与制作依据。MBA 课程的原说明、授权和各轮历史记录完整保存在 [MBA原始说明](迁移记录/MBA原始说明/00-课程规划/课程共识与制作规范.md)，用于追溯，不作为文科版的新任务清单。

## 已确定的课程要求

课程面向文科学院师生，从零基础讲解大语言模型与智能体，不预设编程、深度学习、企业管理或财务知识。首次出现的概念要有足够解释，例子本身不应要求学员先掌握一套陌生业务规则。

课程沿 LLM 基础、Prompting、Agents 展开，在完整介绍大模型智能体后结束。不承接 MBA 课程后续的前沿智能体、企业智能决策等安排，也不把本科课程的十三讲结构与考核要求带入。

在理解基本原理之外，课程更重视学员能把方法与材料带走，应用于日常工作、科研与生活。后续微调应帮助学员回答：怎样交代自己的任务，怎样提供与组织材料，怎样让智能体使用工具，怎样检查结果，以及怎样把有效做法保存下来供下次使用。

教学方式继续使用教师讲解、案例对照与演示。本次不安排练习、小组任务、互评、测验或课堂作业。课后可复用材料与课堂考核是两回事，不从“重视应用”推导出新增作业。

## 内容主线与深度

| 部分 | 要讲清的关系 | 当前取舍 |
| --- | --- | --- |
| LLM 基础 | Prompt 与 Context；文本与 Token；逐 Token 生成；多轮消息组成连续输入 | 展示真实 Tokenization 结果、生成概率及 chat template；不展开分词算法、完整 BPE 或训练数学 |
| Prompting | 目标、背景、Example 与输入组织；让模型协助修改 Prompt；按问题选择方法 | 保留三个前置核心及补充 PDF 中已采用的十种策略，保留完整原始 Prompt |
| 大模型与智能体 | 模型生成内容，Harness 组织执行与反馈 | 保留 Agent = LLM + Harness，区分软件操作与依靠硬件的物理动作 |
| 工具调用 | 模型提出调用，外部程序执行，返回结果进入后续输入 | 用请求、执行、返回解释获取信息与产生影响 |
| Memory 与 Skills | 保存以后需要的信息；保存可复用的方法 | 用文件、读取、输入变化和实际产物解释；完整包与代码在阅读层保留 |
| Protocols 与 Harness | 工具接入和任务委托的共同规则；运行系统怎样组织材料、权限与过程 | 讲清职责、流程和可见结果，不要求记忆协议字段或配置源码 |
| 外化与内化整合 | 模型外部支持与模型能力如何共同变化 | 保留现有概念收束，讲完智能体结束，不自动扩为后续前沿课程 |

## 措辞与案例

沿用 [教师措辞与版式习惯](参考资料/原课程规范/教师措辞与版式习惯.md) 中对标题、句式、概念解释和案例展开的要求。说明应让读者知道谁读了什么、做了什么、依据什么判断。首次出现的英文术语补足中文含义，后文保持称呼一致，不用更多陌生术语解释一个术语。

每页推进一步理解。复杂案例可按背景与材料、关键操作、返回结果和解释分开呈现；条件放在其限定的步骤旁。总分总围绕知识关系组织，不为了形式反复插入相同串场。

优先复用真实文件、已有演示与公开材料；不虚构全课程贯穿故事，不虚构教师经历，不编造运行过程或效果数字。连续案例沿用同一组对象、条件和材料；比较方法时说明改动了什么。

保留原作者与教师原话的属性。原 Prompt 中的填写项、理解检查可以作为引用材料存在，不因此把它们转成学生课堂任务。作者经验不能改写成教师亲历或普遍实证结论。

来源、版本、引用依据与执行记录写入档案。教学正文、图注和阅读区不放制作口吻的免责声明，但应保留理解所需的概念区别、假设和适用条件。不能把未执行的过程说成真实运行，也不能将趋势推演说成已经部署。

## 视觉、文字与配图

采用安泰课件风格 v1：16:9、白底，蓝色标题与细线页眉，深蓝或黑色正文，深红只用于少量重点，右上保留交大建筑轮廓。标题约 32–36 pt，正文约 20–24 pt，图内标签约 18–22 pt；最终以投影可读性为准，不靠缩小字号塞入长材料。

参考 [固定规范快照](参考资料/原课程规范/课件固定规范.md) 与 [三张已确认样张](参考资料/已确认样张/)。只继承适用的风格、措辞和材料原则；其中旧整页生图、PowerPoint 操作、分步正文、考核、特定讲次与任务授权不自动适用于本课。

HTML 中的正文、说明、主要图内标签、提示词和代码使用可选择文字。每个核心机制有解释性配图，优先复用已有图案、文件截图、产物截图和流程图；整页图片不能替代 HTML 正文，普通文字装框或几个大图标不算解释性配图。

论文图表使用对应版本的原图，并保留必要的比较条件、数字和坐标。可裁取相关局部、等比缩放和放大查看，不用生成式图片重画证据。新插图沿用已有视觉体系，不能随工具或模型变化自行更换风格。

## 全显、导航与阅读层

所有普通页面默认一次显示全部信息。只有理解机制需要比较状态时才保留手动控件，支持暂停、回退与对照；不让普通正文、列表和总结逐条点击才出现。

全课程、章节与子章节均按总览、展开、总结组织。分层目录负责定位，知识总览解释关系。底部保留两级课程进度，当前部分标深红，目录与进度可点击跳转。总目录顶部不显示“已结束 → 接下来”横条；章内子目录继续概括上一部分并引入下一部分。

完整 Prompt、消息、文件和代码另设阅读区，可选择、可滚动、可放大。长 Prompt 为黑色纯文本，不通过蓝色或粗体做语法强调，不用摘要替代原文。Prompting 教学界面不增加 PDF 源文件链接，来源追溯留在本地档案。

Memory 与 Skills 过程列表保持固定名称、顺序和字号，只显示截至当前阶段的累积环节；长列表独立滚动，进入页面定位到当前环节，放大与关闭保留阅读位置。

视频使用本地文件、手动播放，支持暂停、定位、调速、声音与放大；视频区按键不触发翻页，离开页面停止。正式预览使用支持 HTTP Range 的 `preview.py`。播放器控件可隐藏，正文不改成普通网页导航布局。
