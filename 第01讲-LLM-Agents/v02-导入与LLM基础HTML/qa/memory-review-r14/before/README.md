## 打开与操作

本地入口为同目录的[index.html](index.html)。本轮浏览器禁止file://访问，直接双击离线播放未能实测；本机预览已完成全讲实播。移动课件时保留整个目录，尤其是`src/`、`assets/`与`sources/`。本机预览：[最新版](http://127.0.0.1:8765/?revision=display-qa-r13#p=1&s=1)。

- 每页底部为两级进度条。深红色表示当前位置；点击一级或二级标题即可跳转。
- 章前目录说明“已结束”和“接下来”，接下来讲的版块标深红。目录用于定位，内容总览仍单独保留。
- `→`或空格：下一页或下一机制状态；`←`：回退。普通页面整页显示，不自动播放。
- `PageDown` / `PageUp`：翻页；`Home` / `End`：全讲首尾。
- `G`：目录；`N`：讲者备注；`M`：完整材料；`Z`或双击图解：放大；`Esc`关闭弹窗。
- `F`：全屏；`H`：隐藏或恢复控制栏；`?`：操作说明。控制栏预留位置固定，自动显隐不挤动页面；按`H`隐藏时释放底部空间。
- 长Prompt用黑色纯文本滚动区。点击文本后，方向键、空格、PageUp/Down、Home/End用于阅读，不翻课件；按`Esc`返回翻页操作。离开页面再返回，文本回到开头。文字可选择复制。

第6页的按钮展开温度、top-k、top-p对照，滑块可用方向键调节。第8页显示完整10步生成轨迹，可点击Token或页内按钮观察不同位置；这些不增加播放器状态数。

第68页为天气消息与chat template双栏对照：点击左侧条目查看对应原始文本，顶部可切换两次完整输入和完整对话；文本可滚动、选择。重置或重新进入该页时回到调用文本。

第92页可查看3个记忆文件；第94、96、97、99页可切换消息条目、关键内容、原始条目和完整输入；第100页比较最初加载、磁盘更新、再次读取。控件可重复操作、重置，离页返回恢复初态。完整采购材料可从这些案例页的“完整材料”打开。

第108页逐个查看12个Skill文件；第113、114、115、117、119页可切换消息、关键内容、完整内容、消息结构与累计内容；第118页查看7个Notebook单元。全部均可重置，离页返回恢复默认。

第139页可切换四份MCP消息的主要内容与完整协议消息；长消息可滚动、选择。重置与离页返回均恢复“发起天气查询”的主要内容。
