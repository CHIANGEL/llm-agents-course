# Memory措辞修订 r15

## 本轮范围

教师认可r14结构、内容形式。本轮只修订Memory的标题、说明、串场句、图内HTML标签、控件说明和对应讲者备注；保留页序、配图、案例数据、原始Prompt与文件内容、互动机制。

## 修订依据

已重新阅读《教师措辞与版式习惯.md》《课件固定规范.md》、课程共识与规划的最新要求，并读取教师第0讲PPT第2、4、9、11页原文。采用“对象、动作明确”“标题直接指出对象或问题”“不反复宣布接下来讲什么”的要求；不机械复制原课金句。冲突的旧制作规则不迁入。

## 实际发现的问题（修改前记录）

- “持续理解用户，持续推进任务”用泛泛的能力描述替代了个性化智能体小结的主题。
- “入口的变化已带来实际限制；能操作界面，还要取得相应的访问和操作空间”表述抽象，实际讨论的是用户授权与平台是否允许自动操作。
- “读到范围之后，10万元被定位为……的条件”句式生硬，可以直接说明预算对应20人、3个月试点。
- 多处页尾只有“接下来打开一个具体任务”“先认识位置和分工；下一页……”“先看……下一页再……”等串场句，与已设置的子目录重复。
- “跨时间的信息”“作用体现在……”“这些安排”等指代抽象，实际对象分别是跨会话记忆、输入中的预算记录、用户提供的信息和权限。
- 图谱页“把不同来源连起来”“把关系接起来”没有直接说出由共同对象关联文档信息的方式。
