## 打开与操作

浏览器打开同目录的`index.html`即可离线播放。移动课件时保留整个目录，尤其是`src/`、`assets/`与`sources/`。本机预览地址为`http://127.0.0.1:8765/`，LLM基础从`#p=4&s=1`开始，Prompting从`#p=15&s=1`开始，Agents从`#p=45&s=1`开始。

- `→`或空格：下一页，或进入必要机制的下一状态；`←`：回退。普通页面一次显示全部内容，无自动播放。
- `PageDown` / `PageUp`：直接翻页；`Home` / `End`：首个 / 最后一个状态。
- `G`：分层目录；`N`：讲者备注与来源；`M`：完整材料。
- `Z`或双击图解：放大图解，可缩放、滚动；`Esc`：关闭展开区。
- `F`：全屏；`H`：隐藏或恢复控制栏；`?`：操作说明。
- 鼠标移到屏幕下沿出现控制栏，可输入页码跳转。

第6页“温度 · top-k · top-p”按钮打开同页参数对照：可调温度、候选数量与累计概率阈值，比较原始和调整后的抽样分布；“返回生成案例”回到原图，重新进入恢复原始分布。滑块支持方向键、Home和End；完整机制说明与数据见材料区。

第8页的10步生成轨迹始终完整可见。用页内按钮或直接点击Token，观察该步的任务、此前已生成内容、候选概率、选中项与累计输出；完整输入模板可在材料区阅读；这些观察位置不计作十个播放器状态。每一步都可回看，不会自动推进。

## 文件与检查

- `index.html`：离线播放入口。
- `src/`：播放器、模块HTML图解、样式及内嵌数据；各内容模块JSON为编辑源。
- `slides.json` / `materials.json`：129页逐页内容、每页时长与时间轴、完整材料与来源。
- `version_manifest.json`：制作范围、当前页码与原规划材料映射、各页状态数及全讲时长。
- `assets/来源.json`：复用图片、字体及校验值。
- `qa/build-data.cjs`：合并LLM基础、Prompting与Agents模块，更新播放数据和版本清单。
- `qa/check.cjs`：浏览器检查全部页面、状态、交互与离线资源。
- `qa/llm-foundations-r2/`：本轮第一部分重构、全讲播放方式调整及实际复查记录。
- `qa/checks.json` / `qa/视觉检查记录.md`、`qa/independent-review/`：此前完整版本的检查与审阅档案，具体覆盖以记录中的版本和页码为准。

Prompting本轮修改与实播覆盖见[Prompting修订与实播记录](qa/prompting-r2/修订与实播记录.md)；第一部分修订见[LLM基础修订记录](qa/llm-foundations-r2/修订与实播记录.md)。此前134页、387状态版本的逐页审阅、控件操作与顺序实播保存在[历史独立审阅记录](qa/independent-review/审阅总记录.md)，不能直接视为当前129页修订版的检查结论。
