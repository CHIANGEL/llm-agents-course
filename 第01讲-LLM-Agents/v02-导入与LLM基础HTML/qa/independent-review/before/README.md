## 打开与操作

浏览器打开同目录的`index.html`即可离线播放。移动课件时保留整个目录，尤其是`src/`与`assets/`。本机预览地址为`http://127.0.0.1:8765/`，后半讲从`#p=50&s=1`开始。

- `→`或空格：下一步；`←`：回退一步。当前页最后一步之后进入下一页，无自动播放。
- `PageDown` / `PageUp`：直接翻页；`Home` / `End`：首个 / 最后一个状态。
- `G`：分层目录；`N`：讲者备注与来源；`M`：完整材料。
- `Z`或双击图解：放大图解，可缩放、滚动；`Esc`：关闭展开区。
- `F`：全屏；`H`：隐藏或恢复控制栏；`?`：操作说明。
- 鼠标移到屏幕下沿出现控制栏，可输入页码跳转。

## 文件与检查

- `index.html`：离线播放入口。
- `src/`：播放器、模块HTML图解、样式及内嵌数据；各内容模块JSON为编辑源。
- `slides.json` / `materials.json`：134页逐页内容、完整材料与来源。
- `version_manifest.json`：制作范围、当前页码与原规划材料映射、各页状态数和时长。
- `assets/来源.json`：复用图片、字体及校验值。
- `qa/build-data.cjs`：合并Prompting与Agents模块，更新播放数据和版本清单。
- `qa/check.cjs`：浏览器检查全部页面、状态、交互与离线资源。
- `qa/checks.json` / `qa/视觉检查记录.md`：完整检查结果与视觉复核记录。
- `qa/screens/`：387个有效分步状态、放大及720p适配截图。
