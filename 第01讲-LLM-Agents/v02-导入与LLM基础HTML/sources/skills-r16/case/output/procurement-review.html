采购评审要点

正式部署 · 软件采购

一、采购条件

使用人数300人
使用期限1年
预算上限30万元

二、费用范围

  • 软件订阅按300人、一年核价，明确版本、税费及计费口径。
  • 配置与迁移、培训与支持分别列明，核对是否包含在预算范围内。
  • 续费、扩容、退出及数据导出费用单列，按相同范围比较报价。

三、交付与管理

  • 按团队分配权限；支持企业账号开通、停用和操作日志。
  • 确认数据托管位置、导出方式及服务终止后的处理安排。

四、待确认事项

  • 供应商完整报价及费用包含范围。
  • 正式上线日期与验收标准。
评审范围：按上述采购条件核对费用、交付及管理要求。
