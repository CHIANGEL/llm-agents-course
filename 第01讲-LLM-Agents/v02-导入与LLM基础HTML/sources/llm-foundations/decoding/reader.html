解码参数：同一份输入，调整下一Token的抽样分布

温度 temperature
T=1保持概率分布；0<T<1使概率更集中；T>1使概率更分散。这里使用T=0.2至2.0。给定原始分数z，调整后的概率为softmax(z/T)。

Top-k
按概率从高到低排序，保留前k项，其余置零，再归一化。“不限”表示不按数量截断。

Top-p（核采样）
按概率从高到低累加，保留累计概率首次达到或超过p的最小候选集合。跨过阈值的最后一项保留。p=1不截断；至少保留一个候选。本例T=1、top-k不限、p=0.50时，前三项合计约49.92%，因此还需保留Today，共四项。

同时使用
演示处理顺序：温度 → top-k → top-p → 最终归一化 → 按概率抽样。top-p根据温度调整与top-k筛选后的归一化分布累计，所以同时改变参数会相互影响。

原案例与抽样
原10步生成使用每步选择最高概率候选。按概率抽样则让保留下来的候选各自有被选中的机会。调整这些解码参数并不修改模型训练所得的权重。

读图
