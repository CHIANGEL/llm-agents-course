本文件夹保存本机Computer Use技能1.0.1001093的接口摘录和短代码。2026-09-30已核对方法名、参数与返回结构；**没有操作应用、没有读取用户窗口、没有真实界面截图或成功日志**。

- `observe.js`：真实API写法；调用后可从state.text获取辅助功能树文本。state.screenshot也可能提供截图。
- `click.js`：真实API写法，编号42取自文档示例；“42对应地址栏”为课堂假设，不能当作本机实测。
- `observe_after.js`：操作后重新读状态。不能把sky.click的Promise<void>返回当作新的截图或完成证明。

## 讲解时区分三个层次

1. 模型生成代码或结构化动作请求。
2. 工具程序调用操作系统或应用提供的接口，实际执行。
3. 新的界面结构或截图回到模型，供它选择下一步。

Qwen天气例子用于展示一份公开模型模板；本节代码用于展示本机工具接口。二者不能拼成“Codex内部也使用Qwen标签”的证据。这里不假定Codex内部聊天模板的具体格式。

本节不编造应用实录。后续如教师要求真实演示，再采集单独、无私人信息的窗口，将截图、结构、调用和结果一并保存。
