## Protocols的官方资料

1. MCP Introduction：https://modelcontextprotocol.io/docs/2026-07-28/getting-started/intro 。核对MCP是连接AI应用与外部工具、数据和工作流的开放标准，以及可复用集成的意义。
2. MCP Tools：https://modelcontextprotocol.io/specification/2026-07-28/server/tools 。核对能力说明、tools/call、天气工具的New York / 72°F / Partly cloudy例子。第8008页只呈现请求中的method、params片段，不宣称该片段是可直接发送的完整消息；不解释协议版本元数据或传输封装。
3. A2A官方文档：https://a2a-protocol.org/latest/ 。核对独立智能体间的任务委托、补充信息、进度与成果；MCP与A2A互补，不以能否多轮对话作互斥分类。
4. A2A官方汇率案例：https://github.com/a2aproject/a2a-samples/blob/main/samples/python/agents/langgraph/README.md 。核对多轮例子的1 USD→追问目标货币→CAD→1.3739 CAD。数字是该文档的示例返回值，不是本轮实时汇率。该实现直接调用Frankfurter API；第8015页说明可组合的架构关系，不将其写成官方汇率案例的MCP执行记录。
5. MDN HTTP Overview：https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Overview 。用于核对浏览器发出请求、服务端返回内容的类比。课堂合称Web标准与协议，不把网页渲染全部归因于单一协议，不展开网络层次。
