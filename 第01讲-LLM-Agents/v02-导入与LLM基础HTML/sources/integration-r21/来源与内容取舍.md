## 事实、推断与课堂假设

- Astra文章证明“更强模型需要不同的外部指导”。文章未公开具体的训练数据来源，不能据此断言某套旧工作流已被Astra逐项内化。
- Harness Annealing提供“外部指导如何被选择性转移到参数”的训练与评估例子，独立支持下一页机制；不把两份来源拼成同一次训练或运行过程。
- “70→80；75→85”来自教师本轮提出的假设。当前画面直接写明“假设在同一组任务上按100分评价”，比较同一评价条件下的模型与Agent配置，不冒充评测数据。
- 将模型改进和Harness调整交替组织为循环，是本课程的归纳。具体某项指导能否删除，仍由任务结果决定；外部实时资料、工具接口与执行约束不因模型变强而消失。
- 搜索了Astra与工作流精简的公开讨论，采用可核验的官方正文，不引用未核验推文。
