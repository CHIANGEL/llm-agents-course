## 官方机制核对

- [Effective context engineering for AI agents](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)：压缩保留关键决定和未解决事项；清理工具长输出；持久记录与子任务隔离。课堂解释为本次输入的组织，不等同于参数训练。原资料保留条件时才可按路径重读。
- [Claude Code Hooks guide](https://code.claude.com/docs/en/hooks-guide)：事件触发配置的动作；采用命令型Hook讲解。Edit或Write成功后的PostToolUse可运行Prettier，原始配置范围未扩大为所有编辑方式。执行前Hook可阻止调用，执行后Hook处理已经发生的结果。
- [Claude Code sandboxing](https://code.claude.com/docs/en/sandboxing)：沙盒的文件与网络边界由运行环境执行；实际覆盖范围必须确认。此产品的Bash沙盒并不自动覆盖文件工具、MCP服务器与Hooks，课件不宣称统一限制所有路径，也不把原图的访问设置称为产品默认值。
- [Claude Code subagents](https://code.claude.com/docs/en/sub-agents)：子代理使用各自上下文、工具和权限，回传结果；运行子任务本身仍消耗资源。课堂保留主代理检查与汇总，以及沟通开销，不承诺一定降低总Token消耗。
- [Effective harnesses for long-running agents](https://www.anthropic.com/engineering/effective-harnesses-for-long-running-agents)：持续记录进度、保存工作文件、恢复时了解当前状态并实际检查结果。课堂提取宏观职责，不搬入完整软件工程流程。

上述页面通过网页工具读取。文件格式整理为官方配置案例；本轮没有启动Claude Code执行该配置，没有生成伪装成实际运行的日志、收据或效果数字。邮件发送与恢复图解释操作机制，不包含实际企业发送记录。运行状态与来源性质只保存在本档案。
