## 事实取舍

- 用户提出的OpenAI—ChatGPT—Codex映射，改为OpenAI—GPT—Codex，并紧接说明ChatGPT与Codex都是应用／产品名称。
- 不把ChatGPT概括成只能聊天的裸模型；它也可以调用工具、组织任务。
- 不把“支持更换模型”表述为任意应用与任意模型都能直接互换。
- 企业版、账号授权与接口兼容是实质条件，直接写在相应例子附近。
