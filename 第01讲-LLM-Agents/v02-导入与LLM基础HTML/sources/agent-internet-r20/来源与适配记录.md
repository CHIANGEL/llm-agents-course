## 图文对应

- 两个用户各有自己的助手，强调个性化信息属于各自的助手。
- 个人助手与平台服务智能体之间以“A2A等”标记双向任务往来，不暗示只有一种可用协议。
- 两侧均可通过MCP使用共享的第三方工具服务；MCP服务没有被画成另一个必须自主规划的智能体。
- 不绘制“全部个人记忆传到平台”的箭头；备注说明只传递任务所需信息。
- 页面默认全部显示，无新分步状态。
