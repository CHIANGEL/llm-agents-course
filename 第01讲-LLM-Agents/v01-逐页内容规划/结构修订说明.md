# 第一讲结构修订说明

更新日期：2026-10-18。依据教师对导入与 LLM 基础 HTML 样稿的反馈。本说明是 v01 后续使用与 v02 修订的结构依据；原 89 页继续作为材料定位档案。

## 本次确定的规则

全讲、章节和子章节均采用“总览—展开—总结”。总览交代本节要讲什么，以及各项内容如何连接；展开沿这个结构逐项讲解；总结回到同一关系图，归纳要点和下一节的连接。目录负责定位，总览负责解释关系。短子节可以在同一页用可回退的分步状态完成总分总，不要求每次机械增加三张独立页面。

课件正文、图注、演示状态和材料展开区清除防御性文字。来源、材料版本和执行记录保存在资料档案；制作时直接呈现有教学作用的材料、动作、机制和概念区别，描述与已有记录保持一致。原稿中的材料性质字段用于归档，不能照搬为课件上的自我说明。

首页在“生成回答”到“执行操作”之间使用红色带叉箭头。全程保留教师讲解、案例对照和演示，不增加练习、讨论任务、测验或作业。

## 全讲层级

导入先说明“回答—操作—交付”之间的关系，再进入分层课程目录。

1. **LLM 基础**
   - 生成：模型怎样逐步生成回答。
   - 上下文：模型这次依据哪些任务与材料。
   - 事实依据：回答怎样回到原材料核对。
2. **Prompting**
   - 任务交代。
   - 澄清关键问题。
   - 核查事实与结论。
   - 比较选择。
   - 验证关键假设。
   - 反馈、修改与检查。
3. **Agents：Externalization & Internalization**
   - 工具调用：模型提出调用，外部系统执行并返回结果。
   - Memory：保存、取回与更新信息。
   - Skills：封装、读取与使用可复用做法。
   - Harness：组织材料、连接、执行、状态与检查。
   - 外化与内化整合：回看外部系统分工，以及训练如何改变模型能力。

Agents 章首以“模型能力—外部系统”分工图解释 Externalization 与 Internalization，之后沿工具、信息、方法、运行过程展开，章末回到同一图整合。两者从目录开始组织内容；原 3–7 部分成为这个一级主题下的五个子模块。

全讲结束时先总结 Agents，再回到 LLM、Prompting、Agents 三个一级主题，连接生成内容、交代任务和组织执行。

## 后续使用方式

制作后续模块时，先从本说明确定层级和总分总，再用旧页码查找现成内容、配图对象和来源。旧文案中的平铺目录、缺少子章总览和总结的串讲方式，以及防御性上屏提示均不沿用。已确定的四个商业案例继续使用：Intercom Fin / Linear、AWS 电子产品客服、Box 文档生成、reMarkable 客服交接；不增设全讲贯穿故事。

实际制作完成后以对应 HTML 版本中的页面清单记录新页码；v01 的 89 页编号保留为材料索引，避免把旧编号和新展示顺序混用。
