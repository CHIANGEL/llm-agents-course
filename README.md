# 零基础入门大模型智能体

面向没有编程或大模型基础的学习者。课程讲清 LLM、Prompting 和智能体的基本原理，更重视把可复用的方法与材料带回日常工作、科研和生活。课程按 LLM 基础、Prompting 和 Agents 的顺序展开，形成完整的入门知识与方法。

## 立即打开

- 公网课件：[零基础入门大模型智能体](https://linjianghao.com/llm-agents-course/)，学院师生无需登录即可访问。
- GitHub 仓库：[CHIANGEL/llm-agents-course](https://github.com/CHIANGEL/llm-agents-course)。课件变更推送或合入 `main` 后自动部署，已打开的网页刷新后显示新版。
- 双击根目录的 **启动课件.command**，启动本机预览并打开浏览器。需要 Python 3；终端窗口保持开启，按 `Ctrl+C` 停止。
- 命令行运行：`python3 scripts/preview-course.py`，然后打开 [本机预览](http://127.0.0.1:8876/?revision=2026-10-21-public-release-r28#p=1&s=1)。
- 无 Python 时，可直接打开 [课件入口](第01讲-LLM-Agents/v02-导入与LLM基础HTML/index.html)。本地视频建议使用上述预览服务，支持拖动定位。

端口默认 `8876`；若占用，可运行 `python3 scripts/preview-course.py --port 8877`。服务只监听本机。移动项目时保留整个目录。

## 当前课件

当前为 **r28，共 202 页、202 个播放器状态**。第 1 页为课程封面，第 2 页为个人介绍，之后接完整教学内容。封面以所提供 PPT 的第一页为依据，讲者信息与所提供的个人介绍材料一致。两页是开场信息，时间表记为 0 秒，没有新增讲授时长。

参考总时长仍为 285 分 40 秒，含第 91 页后的 10 分钟休息；不设休息幻灯片。本课程课次和时长尚未单独安排。现有企业采购、金融等例子仍沿用迁移材料；后续再围绕日常工作与科研生活微调、增加可带走的材料。
