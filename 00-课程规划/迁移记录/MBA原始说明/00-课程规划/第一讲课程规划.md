本讲说明 LLM 怎样生成回答、Prompting 怎样交代任务，以及 Agent 怎样借助工具和运行系统完成工作。以原课程第一、二、三讲及后期 HTML 专题为底稿，保留机制解释，围绕 MBA 学员需要判断的任务目标、资料依据、操作范围和交付结果重新组织。

## 课程主线

LLM 根据当前输入逐步生成内容。Prompting 把目标和必要条件交代清楚。任务涉及查询、计算、文件或外部操作时，需要工具实际执行；Agent 根据返回结果继续决定下一步。Memory 保存以后需要的信息，Skills 保存可复用的做法，Protocols 约定外部交互，Harness 将材料、工具、权限和运行过程组织起来。

Externalization（外化）与 Internalization（内化）从全讲目录开始作为 Agents 部分的组织框架：模型外部的系统怎样组织工具、记忆与方法，哪些方法又可能通过训练成为模型能力。进入Agents时，先用Agent = LLM + Harness定义分工，再用缸中之脑解释模型与外部系统；模型生成、数据查询、网页操作与机械臂视频展开案例，随后回顾定义。然后从认知工件、清单和地图说明外部表示的作用，再区分模型参数、上下文和运行程序，并解释外部经验进入训练的路径；随后依次讲工具调用、Memory、Skills、Protocols 与 Harness，最后用四页讲清模型与Harness共同迭代的闭环，以总目录结束。

本讲希望学员能够解释一次 Agent 操作由谁完成，区分模型知道的内容与本次取得的材料，并判断一个任务还需要哪些执行条件和结果检查。

## 全讲层级与总分总

开头先呈现分层目录，再用总览图说明“生成内容—交代任务—组织执行”的关系。导入首页在生成回答与执行操作之间使用红色带叉箭头，突出后续课程要连接的环节。

3. Agents：Externalization & Internalization。
   - 大模型与智能体：模型输出、软件操作、物理动作，及LLM与Harness的关系。
   - 外化与内化总览：外部表示、三层分工与训练路径。
   - 工具调用：让外部系统执行动作，并把结果送回模型。
   - Memory：保存和取回后续任务需要的信息。
   - Skills：保存和按需使用可复用的做法。
   - Protocols：约定工具与数据交互、跨Agent任务协作。

## 1. LLM 入门基础

### 总览与内部关系

章首只提出两个相连的问题：一段完整回答怎样生成，多轮聊天怎样接续。先沿同一条实际回复看“前文—候选—选择—追加—继续—结束”，再用聊天模板说明每一轮的前文从哪里来。章末回到同一循环，将两部分合为“组织输入，再逐Token生成”，自然接到Prompting。

第一部分不再独立展开访谈事实核查、外部文件读取或同一材料的任务分类。事实与结论检查在Prompting讲，外部记录与模型参数在Memory讲。

### 要讲清的内容

案例对象沿用原课程的讲座取消通知。本轮用固定版本SmolLM2-135M-Instruct实际生成短句`The lecture scheduled for today has been cancelled.`，完整记录10次选择：9个文本Token与1个结束标记。逐页展开真实输入、全词表候选概率、最高概率选择、追加后的完整前文、连续生成轨迹以及句号后继续预测结束标记的过程。候选图保留前5项和“其他”总量，不把少量候选重新归一化。Token只解释为模型处理文本的单位，不展开分词算法。

第8页整条轨迹始终可见，页内按钮用于选择观察哪一步；完整前文、候选概率、选中项和累计输出同步对应，可以回退或直接选择一步。其他LLM基础页一次展示全部内容，不通过翻页键逐条揭示。

随后直接展示原课三轮消息：“3人，每人20元？”→“5人呢？”→“预算80元，差多少？”。聊天气泡与完整模板左右对应，解释system、user、assistant以及消息边界；保留旧问题、旧回答和新追问的原顺序，不将它们改写成条件表。三轮模板分别为5、9、13行，末尾assistant头后就是继续生成的位置。
