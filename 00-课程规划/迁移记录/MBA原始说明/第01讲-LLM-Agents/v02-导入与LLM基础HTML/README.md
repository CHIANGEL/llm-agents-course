## 打开与操作

[最新版预览](http://127.0.0.1:8765/?revision=agenda-clean-r26#p=1&s=1) · [本地入口](index.html) · [页面清单](页面清单.md)

移动时保留整个目录，尤其src、assets与sources。字体、图片、视频、程序和演示数据均为本地资源；新闻与项目外链需联网。视频不自动播放，支持播放、暂停、定位、倍速、声音和放大。离开页面停止播放，返回页面恢复初态；视频区方向键调整进度，空格播放/暂停，不翻页。

本地预览可在本目录运行`python3 preview.py`，再打开`http://127.0.0.1:8765/`。此预览服务支持HTTP Range，用于视频拖动。普通Python http.server不能保证视频定位正常。服务只监听127.0.0.1。

- 方向键或空格翻页，页码输入可直接跳转。页底两级进度和目录可点击。
- G目录、N备注、M完整材料、Z图解放大、F全屏、H隐藏/恢复控制栏、Esc关闭弹窗。
- 长文本可滚动和选择。点击文本区后，方向键与Home/End用于阅读；Esc返回翻页操作。
- 本轮在localhost实际检查；file://双击与其他浏览器未实测，不将资源在本地等同于所有环境已通过。
