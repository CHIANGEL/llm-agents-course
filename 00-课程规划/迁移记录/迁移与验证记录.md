## 重复运行

在项目根目录：

```sh
python3 scripts/preview-course.py
node scripts/verify-independence.cjs
node scripts/verify-playback.cjs
```

浏览器验证需要已安装的 Playwright 和 Chrome/Chromium，可通过 `PLAYWRIGHT_MODULE`、`CHROME_PATH`、`COURSE_URL` 指定。普通播放仅需浏览器；HTTP 预览需 Python 3；内容重建需 Node.js，均不需要相邻 MBA 目录。

旧 `qa/` 下部分脚本带原机器路径、旧页码或旧输出目录，仅保留用于追溯。再次执行之前应适配输入与输出路径；本次验证使用根目录新脚本，历史脚本不是本课启动依赖。
