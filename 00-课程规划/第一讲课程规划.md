# 零基础入门大模型智能体课程规划

更新日期：2026-10-21。文件沿用原名以保持链接稳定，课程按一个完整的入门课程组织。当前 r28 共 202 页，开头为课程封面与个人介绍，后接迁入的完整教学内容；本文明确本课程的定位与后续方向，不代表已经逐页改写教学正文。

## 课程定位与学习目标

面向零基础学习者，从零基础出发，不要求编程、深度学习或商科背景。课程说明大模型怎样生成内容，Prompting 怎样交代任务，智能体怎样借助外部材料、工具和运行系统完成工作。

课程讲完大模型智能体即形成完整收束，不衔接 MBA 后续的前沿智能体或企业智能决策课程。现有外化与内化整合保留为智能体概念的收束；档案中的进一步研究规划不自动成为本课的后续章节。

除理解基础原理外，更重视把方法带回日常工作、科研和生活。后续内容调整围绕以下目标展开：

- 能说明自己要完成的任务，提供必要背景、材料和期望结果。
- 能理解模型生成、外部执行、结果返回各由谁完成，以及输出来自哪些材料。
- 能判断什么时候只需修改 Prompt，什么时候需要工具、跨会话记忆或可复用的方法包。
- 能检查任务结果，把有效提示词、材料组织方式和工作方法保存下来用于类似任务。

继续采用教师讲解、案例对照与演示。上述目标不转为新增课堂练习、测验或作业。

## 课程主线

LLM 根据当前输入逐步生成内容。Prompting 交代目标、背景和期望结果。任务涉及查询、计算、文件或外部操作时，工具实际执行，结果返回后模型继续生成。Memory 保存以后需要的信息，Skills 保存可复用的做法，Protocols 约定外部交互，Harness 将材料、工具、权限和运行过程组织起来。

Agents 先用 `Agent = LLM + Harness` 解释分工，再从外化与内化理解这些组件的关系：外部系统提供材料和执行条件，某些方法也可能通过训练成为模型能力。讲完各组件后回到同一整体，形成完整课程的结尾。

全课程、章节和子章节均按总分总组织。总览解释关系，展开页沿关系讲清具体对象和操作，总结回到相同结构。普通页面一次显示全部信息，必要的机制对照使用页内控件。

当前金融、企业与采购示例仍带有原课程背景。后续若要替换，应成套处理任务条件、材料、操作、结果、完整消息与讲者备注；不能只换标题中的行业名，也不能在本次迁移中宣称已经完成替换。

## 后续微调与材料候选

已确定的主基调是让零基础学员理解原理，并能够把方法用于自己的工作、科研与生活。下表列出可选择的改进方向；本次没有实施，也未确定具体页数、案例替换或交付物。

| 方向 | 可以优先考虑的内容 | 可带走的材料候选 |
| --- | --- | --- |
| 资料阅读与研究准备 | 在给定文献或材料中提取问题、整理观点、比较依据与缺口 | 材料目录示例、阅读 Prompt、来源与结果检查要点 |
| 写作与教学支持 | 交代写作对象、背景、文风和参考样例，比较修改前后 | 可复制 Prompt、样例与修改记录 |
| 日常工作与行政事务 | 从通知、会议材料、活动安排等具体文件解释输入与交付 | 任务说明模板、文件组织示例、交付检查要点 |
| 个人知识与常用方法 | 区分要保存的信息与可复用的做法，说明更新与适用范围 | 记忆条目示例、方法清单或小型技能包 |
| 日常生活 | 用材料整理、计划比较与具体操作说明智能体如何帮忙 | 一个完整任务的输入、过程、结果和复用说明 |

新增示例优先采用可观察的真实材料，降低专业背景负担。每个示例要交代如何迁移到自己的任务：哪些要求可以保留，哪些材料需要替换，哪些结果需要自己检查。它们可以通过教师演示和阅读材料呈现，不自动增加课堂任务。
